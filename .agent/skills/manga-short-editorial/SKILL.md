# 漫画紹介ショート動画（エディトリアル版）作成ガイド

本スキルは、プロジェクト「0001」で確立した**漫画紹介ショート動画（1080×1920 縦型・約60秒）**の構成テンプレート、デザインシステム、Remotionコンポーネント実装規則をまとめたものです。他の漫画作品でもこのルールに従うことで、統一感のある高品質なショート動画を迅速に量産できます。

---

## 1. 動画全体の基本仕様 (Video Specs)

- **解像度**: `1080 × 1920`（アスペクト比 9:16 / 縦型ショート）
- **フレームレート**: `30 fps`
- **総尺**: 約55〜60秒（全12シーン構成）
- **背景**:
  - `theme: 'manga-page'`（通常シーン: 白〜薄アイボリー原稿風背景＋外枠フレーム＋`MANGA SHOKAI // P.XX` 右上スタンプ＋四隅トンボ＋アミ点トーン）
  - `theme: 'manga-dark'`（クライマックス・ラストシーン: 黒背景＋白文字＋ダーク集中線）
  - `fallingMangaBg: true`: 背景で3D漫画単行本・原稿ページが連続して上から下へ立体的に流れる演出（`useGlobalFrame()` 駆動）

## 3. テキスト装飾記法（インラインタグ）

`KineticRichText` および `EditorialBackdrop` で解析・描画される記法です：

- **`[pink:テキスト]`**: 女性キャラクターのセリフ
  - ピンクグラデーション（`#ff2a85` → `#f01c74`）
  - 行全体が `[pink:...]` のみで構成されている場合、自動的に**背後に楕円形コミック吹き出し**が付きます。
- **`[blue:テキスト]`**: 男性キャラクターのセリフ
  - 青グラデーション（`#1d68ff` → `#0047e1`）
  - 行全体が `[blue:...]` のみで構成されている場合、自動的に**背後に楕円形コミック吹き出し**が付きます。
- **`[red:テキスト]`**: 最大強調キーワード（赤グラデーション `#ff2a3b` → `#e01e26`）
- **文字サイズの自動最適化**:
  - 1行かつ6文字以下の短いパンチライン（例: `ヤバすぎた`）: **最大 `132px`** に超巨大化
  - 9〜12文字の標準行: 画面幅の約80〜85%を占めるように **`80〜90px`** に自動拡大
  - 13〜14文字以上の長文: **`72px / 68px`** を維持

---

## 4. セリフ吹き出しの仕様 (Speech Bubble)

- **形状**: 単一SVGパスによる**横長楕円＋左下カーブしっぽ**
- **枠線**: 外枠 `7.5px` の黒ベタ（`#141414`）＋左上の立体縁取り
- **シャドウ**: 右下（`translate(11px, 13px)`）にずらした**黒のアミ点（ハーフトーンドット）パターン影**
- **フィット挙動**: `width: fit-content` でセリフの文字幅に自動フィット。テキストの端が楕円から少しはみ出るレイアウトを許容。

## 5. 新規漫画作品への適用手順

1. **コマ画像の準備**:
   - 切り抜いた漫画コマを `/public/manga/<作品ID>/` に保存（例: `panel_01.png` 〜 `panel_11.png`）
2. **VideoSpec の定義**:
   - `frontend/src/types/editorialSpecs.ts` に `<作品ID>MangaEditorialSpec` を作成
   - シーンテンプレートは上記「2. 標準12シーン構成テンプレート」に沿って配置
3. **プロジェクト追加**:
   - `frontend/src/types/project.ts` の初期プロジェクト一覧または `App.tsx` のテンプレートに追加
4. **音声（VOICEVOX）の適用**:
   - 女性セリフ（ピンク）: 四国めたん / ずんだもん
   - 男性セリフ（青）: 青山龍星 / 玄野武宏
   - ナレーション（黒/白）: 春日部つむぎ / 冥鳴ひまり
   - 各ダイアログの `audioUrl` に音声パスを指定
